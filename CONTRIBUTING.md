# Contributing

Thanks for your interest. Contributions are welcome, especially from people who know Indian languages or run AI systems in production.

1. **Open an issue first** to describe the change, so we can agree on it before you write code.
2. **Keep changes small**, one idea per pull request.
3. **Add or update tests** for any behaviour change, and run them locally with `pytest -q`.
4. **No real personal data** in code, tests or examples. Use made-up values only.
5. **Plain language** in docs and messages.

Starter tasks are labelled `good first issue`. See [ROADMAP.md](ROADMAP.md) for direction.

By contributing you agree your work is released under the project's Apache 2.0 licence.
